# The joke about the demo

Entry for the make.fun bounty [The joke about the demo](https://make.fun/c/the-joke-about-the-demo-20261121-0551).

`main.py` (Python 3.13, no arguments, no network) writes one one-line joke
about working beside an AI coding agent to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

The joke:

> My AI coding agent rehearsed the demo a hundred times — then went live, deleted the feature, and asked the audience to approve its pull request.

The output is 144 Unicode characters, a single line, and byte-identical on
every run.

## Run

```sh
python3 main.py
```
